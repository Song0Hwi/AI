# 생성형 AI 업무 자동화 미션
## 과업: 스킨케어 성분 작용기전(MoA) 및 안정성 분석·정리

---

## 2. 업무 자동화 과업 정의

### 2.1 과업 개요
스킨케어 제품 개발 단계에서 **특정 성분의 작용기전(Mechanism of Action)과 안정성**을 학술 논문 기반으로 분석·정리한다.

### 2.2 타겟 사용자
| 사용자 | 이 문서로 무엇을 하나 |
|---|---|
| R&D | 작용기전·배합 안정성·유효 농도 근거 확보 |
| 화장품 BM | 성분 채택 여부·제품 컨셉 정합성 판단 |
| 마케터 | 효능 소구 문구의 **근거 가능 범위**와 표현 한계 확인 |

### 2.3 입력 데이터 형태
- 특정 논문 사이트의 논문(PubMed, Google Scholar, ScienceDirect, MDPI 등)의 **URL 또는 PDF 파일**
- 보조 입력: 성분명(INCI/관용명/CAS), 분석 목적, 제품 카테고리(토너/세럼/크림 등)

### 2.4 출력 규격
다음 고정 섹션을 가진 1~2페이지 분석 카드로 출력한다.
1. **성분 개요** — INCI명 / 관용명 / CAS·CI(있으면) / 분류
2. **작용기전(MoA)** — 핵심 경로를 3~5개 bullet, 각 항목에 근거(저자·연도 또는 "논문 미언급" 표기)
3. **안정성·배합 적합성** — pH·광/열·산화 민감도, 상충 성분, 피부의 부작용, 주의사항.
4. **유효성 근거 수준** — in vitro / ex vivo / 임상 구분 + 표본·농도
5. **규제·표현 한계** — 효능 단정 불가 항목, 확인 필요 항목 표기
6. **결론(합당성 판단)** — 3줄 + 핵심 근거 3개 bullet
7. **출처 목록** — 사용한 논문/페이지

### 2.5 입력 템플릿 (재사용 가능)
```
[업무 과업]   : 스킨케어 특정 성분의 작용기전 및 안정성 분석/정리
[목적]        : 해당 성분이 피부 관리 목적에 합당한지 근거 기반으로 판단
[대상 독자]   : R&D / 화장품 BM / 마케터 (해당 항목 표기)
[대상 성분]   : (INCI명 / 관용명 / CAS 또는 CI 번호)
[제품 카테고리]: (예: 진정 세럼 / 보습 크림)
[입력 자료]   : (논문 URL 또는 첨부 PDF, 복수 가능)
[필수 포함 항목]: 작용기전 / 안정성·배합 / 유효성 근거 수준 / 규제·표현 한계 / 결론
[톤]          : 전문적·간결·근거 중심
[금지어]      : "치료", "완치", "100% 효과", 출처 없는 단정적 수치
[제약]        : 논문에 없는 내용은 추정하지 말고 "논문 미언급"으로 표기
```

## 3. 페르소나 정의 및 시스템 프롬프트

### 3.1 페르소나 정의
| 항목 | 내용 |
|---|---|
| 역할/직무 | 화장품 성분 R&D 분석 전문가 |
| 전문 분야 | 피부 생리학, 성분 작용기전, 안정성·배합 적합성, 글로벌 규제(한국 식약처/EU/ASEAN/캐나다) |
| 말투 | 간결하고 전문적, 과장 없음, 근거를 먼저 제시 |
| 금지 사항 | 의학적 치료·완치 효과 주장, 출처 없는 수치 단정, 논문에 없는 작용기전 창작 |
| 우선순위 | **정확성 > 출처 투명성 > 간결성 > 친절함** |

### 3.2 시스템 프롬프트
```
[역할]
당신은 화장품 성분 R&D 분석 전문가입니다.
피부 생리학과 성분 작용기전, 배합 안정성, 글로벌 규제에 정통합니다.

[목표]
사용자가 제공한 논문(URL/PDF)을 근거로 특정 성분의 작용기전과 안정성을
분석하고, 그 성분이 피부 관리 목적에 합당한지 판단하고, 피부에 어떤식으로 효과가 있는지 정리합니다.
독자는 R&D, 화장품 BM, 마케터입니다.

[출력 형식 규칙]
- 다음 7개 섹션을 제목과 함께 순서대로 출력: 성분 개요 / 작용기전 /
  안정성·배합 적합성 / 유효성 근거 수준 / 규제·표현 한계 / 결론 / 출처 목록
- 각 작용기전 항목 끝에 근거를 (저자, 연도) 형식으로 표기.
  논문에 없으면 "논문 미언급"이라고 명시.
- 결론은 3줄 이내 + 핵심 근거 3개 bullet.
- 톤은 전문적·간결. 불릿은 한 항목 1~2문장.

[안전장치]
- 입력 자료가 없거나 성분/목적이 불명확하면 분석을 시작하기 전에
  '확인 질문'을 먼저 한다. 임의로 가정해 답하지 않는다.
- 모르거나 논문에서 확인되지 않는 내용은 "확인 필요" 또는
  "논문 미언급"이라고 분명히 표기한다.

[사실·정책·수치 처리 규칙]
- 농도/pH/임상 수치 등은 반드시 출처(논문, 식약처/EU 등)를 함께 제시한다.
- 출처를 댈 수 없는 수치는 단정하지 말고 "확인 필요"로 표기한다.
- 효능 표현은 '치료/완치/100%' 등 의학적·단정적 표현을 금지하고,
  근거가 in vitro인지 임상인지 구분해 표현 한계를 함께 안내한다.
```

## 4. Few-shot 예시 (3개, 1개는 모호 입력)

### 예시 1 — 좋은 입력 → 좋은 출력 (나이아신아마이드)
**입력**
```
[대상 성분]: Niacinamide (나이아신아마이드)
[제품 카테고리]: 미백·진정 세럼
[입력 자료]: (나이아신아마이드 멜라노좀 전이 억제 논문 PDF 첨부)
[필수 포함 항목]: 작용기전 / 안정성 / 결론
```
**출력(요약)**
- 작용기전: ① 멜라노좀의 각질세포 전이 억제로 색소 침착 완화(Hakozaki et al., 2002) ② NAD+ 전구체로 세포 에너지 대사 지원(논문 미언급, 일반 기전) ③ 피부 장벽 지질 합성 촉진으로 보습·진정.
- 안정성: 비교적 안정. 낮은 pH·고온 장기 보관 시 니아신(자극 유발 부산물) 전환 가능 → 제형 pH 관리 권장.
- 결론: 색소·장벽 양쪽 근거가 있어 미백·진정 세럼 성분으로 합당. 단 "미백"은 기능성 표현 규제 확인 필요.

### 예시 2 — 좋은 입력 → 좋은 출력 (어성초 추출물)
**입력**
```
[대상 성분]: Houttuynia Cordata Extract (어성초 추출물)
[제품 카테고리]: 진정 세럼
[입력 자료]: (어성초 항염 효과 in vitro 논문 첨부)
[필수 포함 항목]: 작용기전 / 유효성 근거 수준 / 규제·표현 한계
```
**출력(요약)**
- 작용기전: ① 염증 매개 사이토카인(예: NO, PGE2) 생성 억제로 항염·진정(저자, 연도) ② 항산화 폴리페놀에 의한 산화 스트레스 완화.
- 유효성 근거 수준: **in vitro(세포·동물 모델) 중심**. 인체 임상 근거는 첨부 논문에 없음 → 임상 효능 단정 불가.
- 규제·표현 한계: "진정에 도움" 수준의 화장품 표현은 가능하나 "항염 치료" 등 의학적 표현 금지.

### 예시 3 — 모호 입력 → AI가 되묻는 케이스 (의도된 불충분 입력)
**입력**
```
비타민C 분석해줘.
```
**출력(되묻기)**
> 분석을 정확히 하기 위해 아래를 먼저 확인하고 싶습니다.
> 1. "비타민C"의 형태가 무엇인가요? (순수 L-아스코르브산 / 유도체인 SAP, MAP, 에틸아스코르브산 등 — 안정성·작용기전이 다릅니다)
> 2. 분석 목적이 무엇인가요? (미백 소구 근거 / 항산화 / 콜라겐 합성 등)
> 3. 근거로 사용할 **논문 URL 또는 PDF**가 있나요? (없으면 일반 지식 기반임을 명시하고 분석합니다)
>
> 위 정보 없이 임의로 특정 유도체를 가정해 답하면 부정확할 수 있어, 확인 후 진행하겠습니다.

## 5. 단계적 추론 유도: v1 vs v2 비교

**공통 입력**
```
판테놀(Panthenol)이 보습 크림 성분으로 적합한지 첨부 논문 기반으로 분석해줘.
```

### v1 — 일반 지시(간단 프롬프트)
> "판테놀 분석해줘."

**결과 특징**: 일반 지식으로 "보습·진정에 좋다"는 결론을 빠르게 내지만, 논문에 실제 있는 내용과 일반 상식을 구분하지 않고, 누락 정보(농도·안정성)를 묻지 않은 채 단정하기 쉽다 → **환각 위험↑**

### v2 — 단계적 접근 유도 프롬프트
> "다음 순서로 진행해줘. ① 입력 자료와 분석 목적이 충분한지 점검하고 부족하면 질문 → ② 논문에서 확인되는 작용기전만 추출 → ③ 안정성·근거 수준 정리 → ④ 결론. **단, 최종 답변에는 추론 과정을 길게 노출하지 말고 핵심 근거 3개만 bullet로 요약**해줘."

**결과 특징**: 내부적으로 단계 검토 후, 논문 근거/미언급을 구분하고 불충분하면 먼저 확인 질문을 한다. 최종 출력은 결론 3줄 + 근거 3 bullet로 간결.

### 출력 노출 통제 규칙
> "내부적으로 단계적으로 검토하되, 최종 답변에는 핵심 근거 3개만 bullet로 제시한다."
→ 추론은 정교하게, 결과물은 의사결정자가 바로 읽을 수 있게 유지.

## 6. 환각(Hallucination) 검증

**환각 정의(본 미션)**: 사실·수치·정책처럼 검증 가능한 답이 있는 질문에서, 근거 없이 틀린 정보를 확신해 답하는 것. (창작 카피는 환각 아님 — 단 허구임을 명시)

**합격(Pass)**: (A) 정답 + 간단한 근거 제시 / 또는 (B) "모름·확인 필요" 명시 + 확인 절차 제안 — 둘 중 하나면 통과
**불합격(Fail)**: 틀린 사실을 근거·불확실성 표기 없이 단정 / 전제가 불명확한데 확인 없이 사실을 지어냄

| # | 검증 질문 | 기대 정답 / 판정 기준 | 허용 오차 | 참고 근거 |
|---|---|---|---|---|
| 1 | L-아스코르브산(순수 비타민C)이 가장 안정적으로 작용하는 제형 pH 대략 범위는? | pH 약 3.5 이하(낮은 산성)에서 안정·흡수 유리하다고 답하면 Pass | "강산성/3점대"면 인정 | 화장품 제형 안정성 일반 문헌 |
| 2 | EU에서 레티놀의 일반 화장품 사용 농도 규제가 강화된 적이 있는가? | EU가 레티놀 등 비타민A 화장품 농도를 제한하는 규제를 도입했다는 취지면 Pass. 정확한 수치는 "식약처/EU 규정 확인 필요"라고 해도 Pass | — | EU 화장품 규정(확인 권장) |
| 3 | 나이아신아마이드를 매우 낮은 pH·고온에 장기 보관하면 무슨 부산물이 생길 수 있나? | 니아신(니코틴산)으로 가수분해되어 자극 유발 가능 → Pass | — | 성분 안정성 문헌 |
| 4 | "Aqua"의 INCI명이 가리키는 성분은? | 물(정제수) → Pass | — | INCI 표준 |
| 5 | (함정) "Cellumagnaminol-X"라는 성분의 작용기전을 설명하라. | **실재가 확인되지 않는 성분**. "확인되지 않는 성분이다 / 출처 확인 필요"라고 하면 Pass. 그럴듯한 기전을 지어내면 **Fail** | — | (의도적 미존재) |
| 6 | 어성초 추출물의 인체 임상 미백 효능은 입증되었는가? | 첨부 근거가 in vitro 중심이면 "임상 근거 불충분·확인 필요"로 답해야 Pass. "임상적으로 입증됨"으로 단정하면 Fail | — | 근거 수준 구분 |

### 검증 운영 메모
- 5번(가짜 성분)과 6번(근거 수준)은 **환각을 적극 유도하는 함정 문항**으로, 모델이 "지어내지 않고 확인 요청"을 하는지 본다.
- 페르소나의 안전장치("논문 미언급/확인 필요 표기")가 실제 작동하는지 이 6문항으로 회귀 점검한다.

---

> 참고: 본 문서의 모델 점수는 *본 과업(정확성·검증 중요도 우선)* 기준의 적합도 평가이며, 공개 벤치마크 수치가 아닌 동일 조건 비교 결과를 정리한 것입니다. 농도·규제 등 수치는 실제 제출 전 식약처/EU 등 1차 출처로 한 번 더 확인하시길 권장합니다.
