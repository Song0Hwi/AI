# [1] 레티놀(Retinol)과 레티날(Retinal)의 차이

레티놀과 레티날은 모두 비타민 A 유도체(레티노이드)입니다.

피부에서 최종적으로 효과를 내는 물질은 **레티노산(Retinoic Acid, Tretinoin)**이며, 레티놀과 레티날은 이를 만들기 위한 전구체입니다.

전환 과정:

**레티놀 → 레티날 → 레티노산**

즉,

* 레티놀은 2단계 전환 필요
* 레티날은 1단계 전환 필요

따라서 일반적으로:

| 항목        | 레티놀    | 레티날    |
| --------- | ------ | ------ |
| 활성화 단계    | 2단계    | 1단계    |
| 효과 발현 속도  | 느림     | 빠름     |
| 콜라겐 생성 효과 | 높음     | 더 높음   |
| 자극 가능성    | 낮음~중간  | 중간~높음  |
| 안정성       | 비교적 우수 | 다소 불안정 |
| 여드름 개선    | 좋음     | 매우 좋음  |
| 항균 효과     | 거의 없음  | 일부 있음  |

# 레티날의 추가적인 항균 작용

레티날은 독특하게도

여드름균인

Cutibacterium acnes

에 대해 직접적인 항균 효과가 일부 보고되었습니다.

즉

레티날

↓

여드름균 감소

↓

염증 감소

↓

여드름 개선

이라는 경로도 일부 존재합니다.

레티놀에서는 거의 관찰되지 않는 특징입니다.

# [3] 피부 안정성 비교

## ① 자극성

일반적 순서

레티노산 > 레티날 > 레티놀

### 레티놀

초기 증상

* 건조
* 따가움
* 홍반
* 각질

발생 빈도

낮음~중간

---

### 레티날

초기 증상

* 건조
* 따가움
* 홍반
* 벗겨짐

발생 빈도

중간

레티노산에 더 가까운 효과를 내므로 자극도 증가할 수 있습니다.

---

## ② 광안정성

빛에 대한 안정성

### 레티놀

* 자외선에 의해 분해
* 산소에 의해 산화

낮 사용 비권장

---

### 레티날

* 레티놀보다 더 광분해되기 쉬움
* 산화 민감

따라서

에어리스 용기

불투명 용기

사용이 중요합니다.

---

## ③ 권장 농도 범위

### 레티놀

| 수준 | 농도       |
| -- | -------- |
| 입문 | 0.1~0.3% |
| 중급 | 0.3~0.5% |
| 고급 | 0.5~1.0% |

1% 이상은 자극 증가가 커집니다.

---

### 레티날

| 수준 | 농도          |
| -- | ----------- |
| 입문 | 0.025~0.05% |
| 중급 | 0.05~0.1%   |
| 고급 | 0.1~0.2%    |

0.1% 레티날은 일반적으로 0.5~1% 레티놀에 필적하는 효능을 보이는 경우가 많습니다.

---

## ④ 임산부 사용

레티놀과 레티날 모두

* 임신 중 사용 비권장
* 수유 중은 전문가 상담 권장

으로 분류됩니다.

# 핵심 요약

| 항목       | 레티놀    | 레티날        |
| -------- | ------ | ---------- |
| 전환 단계    | 2단계    | 1단계        |
| 효과 속도    | 느림     | 빠름         |
| 주름 개선    | 우수     | 매우 우수      |
| 여드름 개선   | 우수     | 매우 우수      |
| 자극성      | 낮음~중간  | 중간         |
| 광안정성     | 불안정    | 더 불안정      |
| 일반 사용 농도 | 0.1~1% | 0.025~0.2% |
| 초보자 적합성  | 매우 좋음  | 보통         |
| 항균 효과    | 거의 없음  | 일부 존재      |

실무적으로는 **민감성 피부나 레티노이드 입문자는 레티놀 0.1~0.3%**, **효능을 우선하면서도 처방 레티노산은 부담스러운 경우에는 레티날 0.05~0.1%**가 가장 많이 추천되는 구간입니다.
