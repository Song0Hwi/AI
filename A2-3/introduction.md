# 고객 리뷰 감정 분석 대시보드 (CLI) — 미션 명세서

## 1. 미션 소개

리뷰 1,000건을 읽으려면 사람이 며칠이 걸립니다. AI를 쓰면 몇 분 안에 끝납니다. 그러나 단순 분류하는 것에서 끝나면 의사결정에 써먹기가 어렵습니다. 시간에 따른 감정 변화 추이, 불만 키워드, 별점과 감정의 상관관계까지, 비즈니스 인사이트로 연결되는 대시보드를 만듭니다.

고객 리뷰는 제품과 서비스의 품질을 가늠하는 가장 직접적인 지표입니다. 하지만 수백, 수천 건의 리뷰를 사람이 일일이 읽고 분석하기란 현실적으로 어렵습니다. 이때 AI를 활용하면 대량의 텍스트에서 감정을 자동 분류하고, 핵심 키워드와 트렌드를 빠르게 파악할 수 있습니다.

이 미션에서는 고객 리뷰를 수집하고 AI로 감정 분석한 뒤 대시보드 형태의 시각화 리포트를 생성하는 CLI 기반 서비스를 구현합니다. 단순히 감정을 분류하는 데 그치지 않고, 시간에 따른 감정 변화 추이, 주요 불만/칭찬 키워드 추출, 별점과 감정의 상관관계 등 비즈니스 의사결정에 활용 가능한 인사이트를 도출합니다.

---

## 2. 최종 결과물

다음 기능이 정상 동작하는 **CLI 기반 Python 애플리케이션 1개**를 완성한다.

### 2.1 리뷰 데이터 수집 및 저장

- 외부 파일(CSV/Excel)을 통해 리뷰 데이터를 수집하고, raw/clean 분리 저장이 동작한다.
- 중복 리뷰는 설정에 따라 skip 또는 upsert 처리된다.

### 2.2 AI 기반 감정 분석

- 저장된 리뷰 텍스트를 AI API에 전달하여 감정(긍정/부정/중립)과 감정 점수를 분석하고 저장한다.
- 사용자가 CLI에서 분석 대상과 옵션을 지정할 수 있다.

### 2.3 AI 기반 키워드 및 요약 추출

- 리뷰 전체 또는 감정별 리뷰에서 주요 키워드, 빈출 불만/칭찬 사항을 추출한다.
- 기간별 또는 제품별 리뷰 요약을 생성할 수 있다.

### 2.4 데이터 조회 및 검색

- 리뷰 목록 조회, 상세 조회, 조건 필터링(감정, 별점, 기간), 페이지네이션이 CLI에서 동작한다.
- 감정 분석 결과와 함께 조회할 수 있다.

### 2.5 대시보드 시각화 및 리포트 생성

- 감정 분포, 시간별 추이, 별점-감정 상관관계 등을 차트로 시각화한다.
- 품질 지표와 TOP N 집계가 포함된 종합 리포트를 생성한다.
- 결과를 CSV, 엑셀 파일로 내보낼 수 있다.

## 4. 기능 요구 사항

다음 요구사항을 모두 만족해야 한다.

### 4.1 CLI 설계

- `argparse`를 사용하여 서브커맨드 기반 CLI를 구현한다.
- 필수 서브커맨드: `import`, `add`, `clean`, `analyze`, `extract`, `list`, `show`, `stats`, `dashboard`, `export`
- 각 서브커맨드는 필요한 옵션(예: `--file`, `--sentiment`, `--rating`, `--format`)을 지원한다.

### 4.2 리뷰 데이터 수집

- CSV 또는 Excel 파일에서 리뷰 데이터를 읽어온다.
- 필수 필드: 리뷰 텍스트 / 선택 필드: 별점(1~5), 작성일, 제품명
- 수집된 원본 데이터는 raw 저장소(SQLite 또는 JSONL)에 저장된다.

### 4.3 데이터 정제

- 정제 규칙: 필수 필드 검증, 텍스트 정규화, 별점 범위 검증, 날짜 형식 통일, 짧은 리뷰 필터링
- 중복 처리 정책(skip/upsert)을 적용한다.
- 정제된 데이터는 clean 저장소에 별도 저장된다.

### 4.4 AI 감정 분석

- AI API를 호출하여 감정(긍정/부정/중립)과 신뢰도 점수(0.0~1.0)를 분석한다.
- 분석 대상 선택 옵션(`--all`, `--id`, `--unanalyzed`)을 제공한다.
- API 실패 시 로깅 후 스킵, 이미 분석된 리뷰는 기본 스킵 처리한다.

### 4.5 AI 키워드/요약 추출

- 조건별(기간, 감정, 제품) 리뷰를 종합하여 AI 분석을 요청한다.
- 추출 항목(2개 이상 필수): 긍정/부정 키워드, 전체 요약, 개선 제안
- 추출 결과는 별도 저장하여 대시보드에 활용한다.

### 4.6 데이터 조회

- `list`: 필터링(`--sentiment`, `--rating`, `--date-from/to`), 페이지네이션, 정렬 지원
- `show`: 특정 리뷰 상세 정보(원문, 분석 결과) 출력
- `stats`: 전체 통계 요약(총 리뷰 수, 감정별 비율, 평균 별점) 출력

### 4.7 대시보드 시각화

- matplotlib으로 최소 3종 차트 생성: 감정 분포, 시간별 추이, 별점별 감정 분포
- 한글 폰트 적용, PNG 파일로 저장한다.

### 4.8 리포트 생성

- 품질 지표 2개 이상, TOP N 집계 1개 이상, AI 추출 결과를 포함한다.
- 콘솔 출력 및 파일(TXT/MD) 저장을 지원한다.

### 4.9 데이터 내보내기

- 지원 포맷: CSV, JSONL, Excel 중 최소 2개
- 필터링 옵션(`--sentiment`, `--rating-min`)을 제공한다.

### 4.10 설정 및 로깅

- 설정 파일(`config.json`)로 API 키, 중복 정책, 시각화 옵션 등을 관리한다.
- `logging` 모듈로 INFO/WARNING/ERROR 레벨 로그를 기록한다.

### 4.11 데이터 저장

- 반드시 영구 저장소(SQLite 또는 JSONL 파일)를 사용한다.
- 메모리(List/Dict)만으로 데이터를 관리하면 안 된다.

### 4.12 코드 구조

- 모든 코드를 단일 파일에 작성하면 안 된다.
- 최소 4개 이상의 모듈로 분리한다.

### 4.13 샘플 데이터

- 테스트용 샘플 리뷰 데이터(최소 30건 이상)를 CSV 파일로 함께 제출한다.

## 5. 보너스 과제

- **다국어 감정 분석 지원** — 한국어 외 영어 리뷰도 감정 분석이 가능하도록 구현한다.
- **감정 변화 알림 기능** — 최근 N일간 부정 리뷰 비율이 급증했을 때 경고 메시지를 출력한다.
- **HTML 대시보드 생성** — 생성된 차트들과 통계를 포함한 단일 HTML 파일 대시보드를 생성한다.
- **제품/카테고리별 비교 분석** — 여러 제품 또는 카테고리의 리뷰를 비교 분석하는 기능을 추가한다.

## 6. 개발 환경

- **Python 버전**: Python 3.10 이상을 사용한다.
- AI API 호출을 위한 공식 SDK 또는 `requests` 직접 호출만 사용한다.

## 7. 제약 사항

### 7.1 기능 범위

- 실시간 웹 대시보드는 구현하지 않는다. 정적 차트 이미지와 파일 기반 리포트로 구성한다.
- 실제 쇼핑몰 크롤링은 구현하지 않는다. 파일 기반 데이터 입력만 사용한다.

### 7.2 API 사용

- API 키는 코드에 직접 작성하지 않는다.
- 환경변수 또는 설정 파일로 관리한다.
